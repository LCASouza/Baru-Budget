# Baru Budget v1.0 — Stable

## Status

IN_PROGRESS — architectural analysis delivered on 2026-09-07 (`docs/ARCHITECTURE_ANALYSIS_V1.0.md`). Implementation starts after its approval.

## Objective

Close the first stable version for real family use, with three guarantees: nothing reaches production without passing the tests, the documentation describes what the system actually does, and the security was reviewed end to end instead of assumed.

## Scope

- Continuous integration running lint, build, Vitest and pgTAP on every push and pull request to `main`.
- Security review: the twenty-two `security definer` functions inventoried, their `search_path` and execute grants checked, a scan for versioned secrets, and the client surface confirmed.
- Row level security review: view isolation and function surface covered, closing what the v0.13 matrix does not reach.
- Final suite checked against the list in MASTER_PROMPT section 60.
- Documentation: `README.md` brought up to date, `docs/ARCHITECTURE.md` describing the system as it is, `PROJECT_STATUS.md` reflecting v1.0.
- Backup and import/export validated against the hosted project with real data.
- The desktop and mobile review that v0.13 left pending.
- Version `1.0.0` and a release note.
